# A coding game

#Philosophy

Codes are not only about utility. We see needs, AI helps us implementing functions. But needs never end and we chase in our whole life. 

Coding reveals one's way of problem solving. How one faces mistakes, how one survives complexity, how one handles constraints, etc.. 

Coding makes us rethinking our life philosophy, especially when it does not work. Coding as a way of self-expression forces us going deep into our identity, our principles, our aesthetics. 

Not all code needs a purpose.

#The Goal

To rediscover coding as exploration, creativity, philosophy, and play.
